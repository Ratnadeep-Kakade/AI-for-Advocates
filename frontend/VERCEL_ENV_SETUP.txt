Vercel project environment variables
====================================

Set these for the Production environment (and Preview too only if you want
preview deployments to call the same demo backend):

VITE_API_URL=https://computer-1575-vision--cicero-backend-fastapi-app.us-east.modal.run
VITE_USE_MOCK=false

Redeploy the frontend after saving the variables. Vite variables are baked into
the build, so changing them without redeploying does not update the live site.
